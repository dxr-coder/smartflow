# AI 智能客服系统 — 版本演进路线图

> 本文档是完整成长路线。每个版本不是"加功能"，是**解锁一个新能力维度**。
> 项目名称：SmartFlow — AI 智能客服平台

---

## 产品定位

**一句话**：帮企业解决"内部知识找不到、客服效率低"的问题。

用户（企业员工/客户）提问 → AI 基于企业私有知识库准确回答 → 复杂问题自动创建工单 → 需要时无缝转人工。

**不是聊天机器人 demo，是完整的客服业务系统。**

- 20 个核心概念 + 30+ 面试题笔记

## v2：能用 — 多用户 + 权限 + 业务闭环

**一句话：多人能用，有完整的客服业务流程。**
**简历关键词：JWT 鉴权 + 工单系统 + SSE 流式输出 + PDF + Redis + 多用户隔离**

### 你要学会的

| 概念 | 为什么重要 | 怎么学 |
|------|-----------|--------|
| JWT 认证 | 生产系统必须知道"谁在用" | 注册→登录→拿token→带token请求 |
| 密码哈希（bcrypt） | 密码不能明文存数据库 | 原理+实操 |
| RBAC 权限模型 | 不同角色看不同内容 | 管理员/客服/用户三级权限 |
| SSE 流式输出 | LLM 回答是逐字生成的，用户不想等5秒 | "打字机效果" vs "等完一堆出" |
| PDF 解析 | 实际文档大多是 PDF | pypdf 提取文本 |
| Redis 缓存 | 省 Token 费用，加速重复问题 | 语义缓存策略 |
| async/await | FastAPI 的真正看家本领 | 结合 SSE 流式输出学 |

### 功能清单

**用户系统**
- 注册 / 登录（JWT，access_token + refresh_token）
- 三级角色：管理员 / 客服 / 普通用户
- 权限隔离：管理员看全部，客服看分配的对话，用户只看自己的

**工单系统**
- 用户发起工单（退款/投诉/咨询）
- AI 自动分类工单类型
- 状态流转：待处理 → 处理中 → 已解决 → 已关闭
- 超时未处理自动提醒

**转人工机制**
- AI 连续 2 次回答"不确定" → 建议转人工
- 用户主动说"转人工" → 触发转接
- 人工客服接入后 AI 退场

**其他**
- SSE 流式输出（回答逐字显示）
- PDF 文档上传 + 解析
- 语义缓存（Redis）
- 使用配额（普通用户每天 50 次）

### 里程碑
- M1：JWT 认证（注册/登录/Token 刷新）
- M2：用户角色 + 权限中间件
- M3：工单系统（创建/查询/状态流转）
- M4：转人工机制
- M5：PDF 解析 + SSE 流式输出 + Redis 缓存

### 交付物
- 完整后端代码（FastAPI）
- API 接口文档（Swagger/ReDoc）
- 数据库设计文档（ER 图）

## v3：能看 — 前后端分离 + 数据分析

**一句话：有完整的管理后台和用户端界面。**
**简历关键词：Vue3 + WebSocket + ECharts + 数据看板 + Agent 推理可视化**

### 你要学会的

| 概念 | 为什么重要 | 怎么学 |
|------|-----------|--------|
| Vue3 前端框架 | 简历上要写"全栈" | Composition API + 组件化 |
| WebSocket | 实时通知（新工单/转人工） | 对比 HTTP vs WebSocket |
| ECharts 数据可视化 | 监控面板要有图表 | 折线图/饼图/柱状图 |
| Agent 推理可视化 | 展示 AI 思考过程，提升用户信任 | 实时展示每步决策 |
| 前后端联调 | 真实开发流程 | API 对接 + 错误处理 |

### 功能清单

**用户端界面**
- 聊天窗口（气泡 + Markdown 渲染 + 打字机效果）
- 历史对话列表
- 工单提交 / 查看进度
- Agent 推理过程实时展示

**管理后台**
- 知识库管理（上传/预览/删除文档）
- 工单管理（列表/详情/状态流转/分配客服）
- 用户管理（角色分配/禁用/启用）
- 数据看板（ECharts）
  - 每日对话量趋势
  - AI 自动解决率
  - 平均响应时间
  - 热门问题 Top10
  - Token 消耗趋势
  - 用户满意度分布

**实时通知**
- WebSocket：新工单 → 实时推送给客服
- WebSocket：转人工请求 → 实时通知在线客服

### 里程碑
- M1：Vue3 项目搭建 + 聊天界面
- M2：对话列表 + 消息历史
- M3：工单管理界面
- M4：管理后台（用户管理 + 知识库管理）
- M5：数据看板（ECharts）+ Agent 推理可视化

### 交付物
- 完整前后端分离项目
- 项目演示视频（2-3 分钟）
- 技术博客（面试加分）

## v4：能强 — 多 Agent 协作 + 智能决策

**一句话：复杂问题多 Agent 协作解决，系统能自主决策。**
**简历关键词：Multi-Agent + LangGraph 状态机 + 插件系统 + 工作流引擎**

### 你要学会的

| 概念 | 为什么重要 | 怎么学 |
|------|-----------|--------|
| Multi-Agent | 单 Agent 解决不了复杂任务 | 设计意图分类→路由→协作 |
| LangGraph 状态机 | 复杂工作流编排 | 节点/边/条件分支/并行 |
| 插件系统 | 可扩展，不改核心代码加新功能 | 反射 + 约定大于配置 |
| 自动摘要 | 长对话压缩 token | 对话超过 N 轮自动总结 |

### 功能清单

**多 Agent 协作引擎**
- 分类 Agent：判断用户意图（知识库问答/查订单/转人工/闲聊）
- 知识库 Agent：专门做 RAG 检索和回答
- 工单 Agent：专门处理工单创建/查询/流转
- 搜索 Agent：知识库没有时联网搜索补充
- 协调 Agent：决定调哪个 Agent，汇总结果

**工作流引擎（LangGraph）**
- 可视化流程编辑器（拖拽配置 Agent 流程）
- 条件分支（"退款类 → 走退款流程"）
- 并行执行（同时搜索多个知识库）

**插件系统**
- 新工具只需写一个文件，自动注册
- 内置插件：计算器/网页搜索/SQL 查询/代码执行
- 插件热加载（不重启服务加新工具）

**其他**
- 对话分支（同一问题生成多个回答，用户选择）
- 自动摘要（长对话压缩 token）
- 知识库自动更新（文档变更 → 重新切分+向量化）

### 里程碑
- M1：意图分类 Agent
- M2：多 Agent 路由 + 协调
- M3：插件系统 + 工具自动注册
- M4：LangGraph 工作流引擎
- M5：对话分支 + 自动摘要

### 交付物
- 多 Agent 协作系统
- 插件开发指南
- 架构设计文档（面试谈资）

## v5：能上线 — 生产级部署

**一句话：安全、可靠、可扩展、成本可控的生产级系统。**
**简历关键词：Kubernetes + CI/CD + 安全加固 + 成本优化 + 压力测试**

### 你要学会的

| 概念 | 为什么重要 | 怎么学 |
|------|-----------|--------|
| K8s 部署 | 大厂部署标准 | Deployment + Service + Ingress |
| CI/CD | 代码推送自动构建部署 | GitHub Actions |
| 安全加固 | OWASP Top 10 实战 | SQL注入/XSS/CSRF 防护 |
| 成本控制 | Token 费用是真金白银 | 缓存+模型路由+预算控制 |
| 压力测试 | 知道系统能扛多少人 | locust 压测 + 报告 |

### 功能清单

**部署**
- K8s 部署（Deployment + Service + Ingress）
- HPA 自动扩缩容
- 蓝绿部署（零停机更新）

**CI/CD**
- GitHub Actions：push → 测试 → 构建 → 部署
- 自动化回归测试

**安全**
- SQL 注入防护（参数化查询）
- XSS 防护（前端转义）
- 速率限制（Redis + 滑动窗口）
- 文件上传校验（类型+大小+病毒扫描）
- 日志脱敏（密码/token/手机号不记录）

**成本控制**
- 语义缓存（相似问题直接返回）
- 模型路由（简单问题用便宜模型）
- Token 预算（单次对话上限）

**可观测性**
- Prometheus 指标采集
- Grafana 监控面板
- 错误告警（钉钉/飞书 Webhook）

**压力测试**
- locust 压测脚本
- 测试报告（QPS / P99 延迟 / 错误率）
- 扩容方案

### 里程碑
- M1：K8s 部署配置
- M2：CI/CD 流水线
- M3：安全加固
- M4：成本优化
- M5：压力测试 + 扩容方案

### 交付物
- 完整生产级项目
- 部署文档 + 运维手册
- 压力测试报告
- **面试故事**："我从零搭建了一个生产级 AI 智能客服系统，从架构设计到 K8s 部署全部自己完成"
