# SmartFlow 助手使用指南

版本：1.0
生效日期：2026-01-01
适用范围：全体员工
归口部门：客户成功中心 / 技术中心

---

## 一、SmartFlow 是什么

- SmartFlow 是星辰科技自研的 AI 智能客服与知识问答助手
- 内部版部署在企业微信与内网门户（portal.starcorp.com），外部版面向客户
- 能力：知识库问答（带引用溯源）、工单创建与查询、制度咨询、报障升级
- 底层：混合检索（关键词 + 向量）+ 重排序 + 大模型生成，答案标注来源文档与段落

---

## 二、入口与登录

### 2.1 入口
- 企业微信：工作台 → SmartFlow 助手
- 内网门户：portal.starcorp.com → 智能助手
- Web 端：smartflow.starcorp.com（需先连内网或 VPN）
- 移动端：企业微信内嵌，无需单独安装

### 2.2 账号
- 使用企业邮箱账号登录，无需单独注册
- 首次登录自动同步组织架构与权限
- 权限跟随岗位：普通员工可问答与提工单，坐席可处理工单，管理员可进后台
- 登录异常联系 IT 服务台（分机 8100）

## 三、核心功能

### 3.1 知识库问答
- 直接用自然语言提问，例如"会议室最多能提前几天预订"
- 助手从知识库检索相关制度文档，生成答案并标注引用来源
- 答案下方显示来源文档名与段落，点击可查看原文
- 置信度低时助手会提示"建议人工确认"或引导创建工单
- 知识库覆盖：HR 制度、IT 指南、行政规范、财务报销、合规手册等

### 3.2 工单创建与查询
- 说"我要报修"或"创建工单"即可发起
- 填写问题描述、紧急程度、相关部门，系统自动路由
- 查询进度：说"我的工单怎么样了"或"查一下工单 123"
- 工单状态：待处理 → 处理中 → 已解决 → 已关闭
- 超时未处理会自动升级（SLA 见《IT服务指南》紧急 15 分钟响应）

### 3.3 制度咨询
- 覆盖常见制度问题：请假、报销、考勤、社保、办公用品、会议室
- 答案引用制度原文，避免口口相传失真
- 助手不确定时不会编造，会引导联系对口部门
- 制度有更新的，助手答案随知识库同步更新

### 3.4 报障与升级
- IT 故障：助手初筛 → 无法解决自动转 IT 服务台工单
- 紧急事件（全公司断网、核心系统宕机）：助手提示拨打紧急联系人，同时 7×24 响应
- 助手可查询工单处理人与预计解决时间

## 四、坐席端功能

### 4.1 工单处理
- 坐席登录可看到分配给本组的工单队列
- 支持转接、升级、添加内部备注、关联知识库条目
- 处理完成后填写解决方案，客户确认后关闭
- 转接规则见《客户支持工单处理规范》

### 4.2 满意度评价
- 工单解决后向提交人推送 CSAT 评分（1-5 星）与评语
- 评分进入坐席绩效，top-2-box（4-5 星占比）为核心指标
- 一单一评，重复提交会被拒绝

---

## 五、后台管理（管理员）

### 5.1 知识库管理
- 上传制度文档（支持 md、pdf、docx），自动切片与向量化
- 文档版本管理：同名重传自动升版本，历史版本可查
- 支持按部门限定文档可见范围（hr / it / admin / finance / all）

### 5.2 数据看板
- 会话量、解决率、响应时长、满意度趋势
- 知识库命中率与未命中问题清单（用于补知识）
- 坐席工作量与评分分布

### 5.3 A/B 实验与评测
- 支持检索策略 A/B 实验，按用户分组对比 CSAT 与检索指标
- RAG 评测：金标集 + Hit@1 / Recall@5 / MRR 检索质量回归
- 详见《RAG 评测说明》（内部wiki）

## 六、常见问题

**Q：助手回答错了怎么办？**
A：点击答案下方"反馈"按钮标记错误，或在工单中说明。反馈会进入知识库优化清单，坐席核实后更新文档。

**Q：助手能处理哪些工单，哪些要找人？**
A：常见制度咨询、密码重置指引、报障初筛助手可直接处理；涉及审批、权限变更、复杂故障会转人工。

**Q：我的提问会被谁看到？**
A：对话记录用于知识库优化与服务质量分析，严格按数据分级管理，仅授权人员可访问，不会外传。

**Q：助手支持哪些语言？**
A：目前以中文为主，英文常见咨询可支持，复杂问题建议转人工。

**Q：发现助手引用的文档过时了？**
A：联系文档归口部门更新，或在助手反馈中标注。知识库文档更新后，助手答案自动同步。

**Q：能查到我的工资、绩效吗？**
A：不能。助手不接入个人薪酬、绩效等敏感数据，这些信息通过 OA 个人中心或 HRBP 查询。
