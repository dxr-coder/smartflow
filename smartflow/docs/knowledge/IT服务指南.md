## 一、账号与权限

### 1.1 账号类型
- 企业邮箱：firstname.lastname@starcorp.com，入职自动开通
- OA 系统：与邮箱同名，首次登录需修改初始密码
- VPN 账号：远程办公必备，向 IT 服务台申请
- 内网系统账号：按岗位需要申请，需部门负责人审批

### 1.2 密码规范
- 密码长度不少于 12 位，包含大小写字母、数字、特殊符号中至少 3 类
- 密码有效期 90 天，到期强制更换
- 不得与最近 5 次使用过的密码重复
- 禁止多人共用账号，因共用账号导致的安全事件由账号所属人承担责任

### 1.3 权限申请
- 新员工权限：入职单默认开通基础权限（邮箱、OA、内网）
- 增加系统权限：在 OA 提交权限申请单，直属主管 + 系统 Owner 审批
- 权限回收：转岗时原权限 3 个工作日内回收，离职当日全部回收
- 特权账号（数据库、服务器）：需 CTO 审批，使用需开启操作录屏

### 1.4 账号锁定
- 连续 5 次密码错误，账号锁定 30 分钟
- 账号锁定后可联系 IT 服务台解锁，需验证工号和姓名
- 疑似被盗：立即联系 IT 安全组（分机 8110），必要时强制下线所有会话

## 二、设备管理

### 2.1 设备领用
- 入职配发：笔记本电脑（MacBook Air / ThinkPad）、显示器、键鼠
- 领用流程：行政部签字确认领用单 → IT 部门配置设备 → 员工签字领取
- 设备资产编号贴在机身底部，报修时需提供

### 2.2 设备使用规范
- 笔记本电脑仅限本人使用，不得安装与工作无关的软件
- 禁止私自拆机、改装硬件
- 禁止使用个人 U 盘拷贝公司数据，如需传输使用企业网盘
- 笔记本电脑必须设置开机密码 + 屏保密码（5 分钟自动锁屏）
- 离开工位超过 10 分钟应锁屏（Windows：Win+L，Mac：Ctrl+Command+Q）

### 2.3 设备维修
- 保修期内：联系 IT 服务台报修，IT 协调厂商上门或送修
- 保修期内非人为损坏：免费维修
- 人为损坏（进水、摔坏、私自拆机）：维修费用由个人承担
- 维修期间 IT 可提供备用机（需抵押工牌）

### 2.4 设备更换与归还
- 电脑使用满 3 年可申请更换，需部门负责人审批
- 离职时设备原样归还（含电源线、扩展坞），IT 检查后签字
- 设备遗失或损坏无法修复：按折旧价赔偿（3 年折旧完毕）

## 三、网络与 WiFi

### 3.1 办公网络
- 有线网络：插网线自动获取 IP，无需配置
- 办公 WiFi：SSID 为 StarCorp，使用企业邮箱账号密码连接
- 访客 WiFi：SSID 为 StarCorp-Guest，通过手机验证码登录，限速 10Mbps

### 3.2 常见 WiFi 故障排查

**无法搜索到 StarCorp 信号：**
1. 确认电脑 WiFi 开关已打开（部分机型有物理开关或 Fn 快捷键）
2. 忘记网络后重新搜索：系统设置 → 网络 → WiFi → 忘记 StarCorp → 重新连接
3. 检查是否在信号盲区（会议室、地下室），换位置重试
4. 重启电脑的无线网卡：设备管理器 → 网络适配器 → 禁用 → 启用

**能搜到信号但连不上：**
1. 忘记网络，重新输入账号密码（注意密码区分大小写）
2. 检查是否超过设备数限制（同一账号最多 3 台设备在线）
3. 释放并更新 IP：命令行执行 ipconfig /release 和 ipconfig /renew（Windows）
4. 重置网络设置：设置 → 网络 → 网络重置（Windows 10/11）

**连接成功但无法上网：**
1. 打开浏览器访问任意 HTTP 网站，检查是否弹出 Portal 认证页面
2. 确认 VPN 是否需要开启（访问内部系统需先连 VPN）
3. ping 114.114.114.114 测试是否能通（通则 DNS 问题，不通则网络问题）
4. 检查 IP 冲突：ipconfig /all 查看 IP，联系 IT 确认是否与他人冲突

**网络频繁断连：**
1. 更新无线网卡驱动程序
2. 关闭省电模式：设备管理器 → 网络适配器 → 属性 → 电源管理 → 取消"允许计算机关闭此设备以节约电源"
3. 5GHz 和 2.4GHz 频段切换尝试
4. 如多台设备均出现，联系 IT 检查 AP 状态

### 3.3 远程办公
- VPN 下载：内网门户 → IT 服务 → VPN 客户端
- VPN 连接：使用企业邮箱账号 + 动态令牌（企业微信小程序获取）
- VPN 限速：上下行各 50Mbps，视频会议优先
- 连不上 VPN：先确认动态令牌是否过期（30 秒刷新），再检查防火墙是否放行

## 四、软件安装

### 4.1 标准软件清单
- 办公套件：Microsoft 365（公司统一授权）
- 即时通讯：企业微信
- 代码开发：VS Code、JetBrains 全家桶（公司许可证）
- 设计工具：Figma（团队版）
- 终端工具：iTerm2（Mac）、Windows Terminal（Windows）

### 4.2 安装规范
- 标准清单内软件：可通过内网软件商店自助安装，无需审批
- 清单外软件：在 OA 提交软件申请，说明用途，IT 安全审核后安装
- 禁止安装：破解版软件、来路不明的软件、挖矿程序、翻墙工具
- 付费软件：公司统一采购许可，个人不得私自购买安装到公司设备

### 4.3 软件故障
- 软件崩溃：先重启软件，再重启电脑，仍无法解决联系 IT 服务台
- 提供信息：软件名称、版本号、错误截图、操作步骤
- IT 远程协助：企业微信 → IT 服务台 → 申请远程协助

## 五、信息安全

### 5.1 钓鱼邮件识别
- 发件人地址与显示名不一致
- 要求立即点击链接、输入密码、转账
- 邮件中有紧迫性用语（"账号将被冻结"、"24小时内处理"）
- 附件为 .exe、.scr、.zip 等可执行文件
- 收到可疑邮件：不要点击，转发至 security@starcorp.com

### 5.2 数据安全分级
- 公开级：可对外发布（产品介绍、招聘 JD）
- 内部级：仅限公司内部（制度文档、会议纪要）
- 机密级：限定知悉范围（财务数据、客户名单、代码仓库）
- 绝密级：仅限核心管理层（并购计划、融资信息、未公开财报）

### 5.3 安全事件上报
- 发现电脑异常（蓝屏频繁、弹窗异常、文件被加密）：立即断网并联系 IT 安全组
- 怀疑账号泄露：立即修改密码，联系 IT 安全组排查
- 数据误发：立即联系 IT 安全组尝试召回，同时通知收件人删除
- 安全事件热线：分机 8110（7×24 小时）

### 6.4 常见问题

**Q：忘记电脑开机密码怎么办？**
A：携带工牌到 IT 服务台重置。Mac 需提供购买凭证（公司统一管理的可直接重置）。

**Q：需要安装正版 Photoshop 怎么办？**
A：在 OA 提交软件申请，说明业务用途。设计岗标配，其他岗位需部门负责人 + IT 审批。

**Q：手机能连公司 WiFi 吗？**
A：可以。连接 StarCorp 后会弹出认证页面，使用企业邮箱账号登录，每天需重新认证。

**Q：怎么申请更大的网盘空间？**
A：企业微信网盘默认 50GB，在 IT 服务台提交扩容申请，部门负责人审批，最高可扩至 500GB。
