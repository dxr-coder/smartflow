# 星辰科技费用报销系统操作手册

版本：2.1
生效日期：2026-01-01
适用范围：全体员工
归口部门：财务部

---

## 一、系统概述

### 1.1 系统入口
- OA 系统：内网门户（portal.starcorp.com）首页顶部导航"费用管理"，或企业微信"工作台 → OA → 报销中心"
- 移动端：企业微信工作台"报销"应用，支持拍照上传发票、语音输入事由
- SmartFlow 助手：可查询报销制度、审批进度、到账时间（问答类咨询），不能代替提交报销单
- 首次登录使用域账号（邮箱前缀）+ 企业微信扫码双重认证；密码问题联系 IT 服务台（分机 8100）

### 1.2 单据类型总览

| 单据名称 | 用途 | 典型场景 |
|---------|------|---------|
| 费用报销单 | 日常费用报销 | 招待费、办公用品、打车、快递费 |
| 差旅报销单 | 出差费用报销 | 交通、住宿、伙食补贴（必须关联出差申请） |
| 借款单 | 因公借款 | 出差备用金、采购定金 |
| 冲账单 | 借款核销 | 用发票/报销冲销借款余额 |
| 付款申请单 | 对公付款 | 供应商货款、服务费、房租物业 |
| 紧急付款申请 | 加急支付 | 当天到账的特殊支付（需财务经理特批） |

### 1.3 界面布局说明（截图式描述）
- 左侧边栏：待我处理、我发起的、我审批的、常用模板、统计报表
- 中部主区域：表单填写区，自上而下依次为"基本信息 → 明细行 → 附件区 → 审批流程预览"
- 右侧浮层：制度提示（自动匹配金额档位的审批要求）、预算余额实时显示
- 底部操作条：暂存、提交、退回修改（仅审批人可见）、同意、驳回（仅审批人可见）

## 二、差旅报销单操作（逐步）

### 2.1 事前：完成出差申请
1. OA 首页 → 费用管理 → 出差申请 → 新建出差申请
2. 填写出差城市（支持多城市，逐个添加）、出发与返回日期、同行人
3. 城际交通方式预选：高铁/飞机/自驾，系统按职级校验舱位（普通员工选不到高铁商务座选项）
4. 预计费用：交通、住宿、其他三项分别预估，合计超过 5000 元需在事由栏说明构成
5. 提交审批：跨市且 5 天以内/省内为直属主管；5 天以上或跨省为部门负责人
6. 审批通过后，出差申请单号出现在"已通过出差申请"列表，供差旅报销单关联

### 2.2 报销：填写差旅报销单
1. 费用管理 → 差旅报销单 → 新建，系统弹窗提示"请选择要关联的出差申请"，勾选对应申请（未审批通过的不显示）
2. 基本信息区：出差地点自动带出；报销期间默认为出差起止日，可微调；事由自动带出出差事由，可补充
3. 交通明细行：点击"添加交通记录"，逐段填写——日期、区间（如"北京-上海"）、方式、金额、票据号；上传对应行程单 PDF
4. 住宿明细行：入住日期、离店日期、城市、酒店名称、金额、超标自付金额（系统按城市等级与职级自动计算封顶额，超出部分自动填入"自付金额"列，无需手改）
5. 伙食补贴区：系统按出差天数自动计算——出发日与返回日各算半天，跨市出差 100 元/天；页面会显示"客户已包餐 X 餐需扣减"复选框，按实勾选
6. 市内交通行：按天填写金额并合计，不得超过职级日上限（普通员工 80 元/天、经理 100 元/天、总监及以上 200 元/天），超限部分系统自动列入自付
7. 自驾行（如有）：填写公里数，系统按 1.2 元/公里计算补贴，需上传行程单截图
8. 合住奖励：若与其他同性别同级别同事合住，在住宿行勾选"合住"并填写同行人，系统按节省部分的 50% 计算奖励金额，奖励与报销款一并打入工资卡
9. 底部预览"本次报销合计"，确认票据总额与差额（自付部分）无误后暂存或提交

### 2.3 时限提醒
- 系统在出差结束后第 1 个工作日推送企业微信提醒："请在 10 个工作日内提交差旅报销"
- 超过 10 个工作日未提交，提醒升级发送给直属主管
- 超 30 天的单据提交时强制弹出超期说明框，需部门负责人审批意见中确认

## 三、费用报销单操作（逐步）

### 3.1 新建与模板
1. 费用管理 → 费用报销单 → 新建
2. 顶部"常用模板"：可将常用组合（如"打车+快递"）存为模板，下次一键带出明细结构
3. 费用类型下拉必选，常见类型：业务招待费、市内交通费、办公用品、快递费、培训费、通讯费、其他（选"其他"必须填写说明，财务审核会从严）

### 3.2 明细行填写
- 每行一条费用：日期、费用类型、金额、发票号码、事由
- 招待费：系统强制填写客户名称、参与人数、人均金额；人均超 300 元或单次总额超 3000 元的，自动追加"部门负责人 + 财务负责人"审批节点
- 培训费：关联 HR 培训预算，系统显示本人当年已用培训额度/5000 元年度预算；超额的提示个人承担
- 打车费：支持导入滴滴企业版账单一键生成明细行；手动添加需上传行程单并备注事由（加班 21 点后、携带设备、多人同行等）

### 3.3 附件上传规范
- 电子发票：只接受 PDF 原件，单个文件不超过 20MB，多张可打包 zip（zip 内保持原 PDF 文件名）
- 纸质发票：拍照或扫描为 PDF/JPG，保证四角完整、金额清晰可辨
- 每个明细行至少关联 1 个附件，无附件的行需选择"无票支出"并走情况说明流程（单笔上限 100 元，每月不超过 3 次）
- 附件命名建议：日期_类型_金额（如 20260115_招待费_1280.pdf），便于财务审核核对

## 四、借款单与冲账单

### 4.1 借款单
1. 费用管理 → 借款单 → 新建
2. 借款类型：出差备用金 / 采购定金 / 其他（其他需 CFO 事前同意）
3. 金额：省内 3000 元、跨省 5000 元、出境 10000 元为常规上限，超出需说明
4. 预计冲账日期：默认为借款后 30 天，出差借款默认按出差结束日 + 10 个工作日
5. 审批矩阵与报销一致：2000 元以下直属主管；2000-5000 直属主管+部门负责人；5000-20000 部门负责人+财务经理；20000 以上加 CFO
6. 提示规则：本人有未冲账借款时，提交按钮旁红色提示"存在未冲销借款，原则上不可新增借款"，仍坚持提交的需部门负责人在意见中说明

### 4.2 冲账单
1. 费用管理 → 冲账单 → 新建，系统自动列出未清借款
2. 选择要冲销的借款单，输入冲账金额（支持部分冲账）
3. 关联报销单：若差旅报销单已提交，可直接关联自动冲抵；也可先提交冲账单再提交报销单，系统按提交时间顺序自动抵扣
4. 冲账后仍有余额（借多报少）：系统生成"应退回金额"，员工在 7 个工作日内通过网银退至公司账户，上传退款回单完成闭环
5. 报销金额大于借款的：差额部分正常走报销付款流程

## 五、付款申请单（对公）

### 5.1 填写要点
1. 收款单位：从供应商台账选择（新供应商先在台账"新增供应商"，财务审核后可用）
2. 合同编号：必填（2000 元以上），关联合同台账；无合同的 2000 元以下零星支出选择"无合同零星支出"并上传说明
3. 发票信息：录入发票代码/号码或上传 PDF，系统校验是否已在其他付款单中使用
4. 付款节点：预付款/进度款/尾款/质保金，选择进度款以上节点需上传验收单
5. 金额与币种：默认人民币；外币付款需财务经理审批并备注汇率锁定安排
6. 收款账户：从供应商台账带出，变更账户的须供应商提交盖章变更函，财务经理审批后台账更新

## 六、提交、审批与驳回

### 6.1 提交前自查清单
- [ ] 单据类型选对（差旅费必须用差旅报销单，不能用费用报销单）
- [ ] 差旅报销单已关联有效出差申请
- [ ] 金额合计与附件发票合计一致
- [ ] 电子发票均为 PDF 原件
- [ ] 抬头均为"星辰科技有限公司"
- [ ] 时限内（费用 30 天内、差旅出差结束后 10 个工作日内）
- [ ] 预算余额充足（右侧浮层显示绿色）
- [ ] 事由填写完整（一句话说清什么业务、什么客户/项目）

### 6.2 审批流转
1. 提交后按金额档位自动路由：2000 元以下到直属主管；2000-5000 加部门负责人；5000-20000 到财务经理；20000 以上加 CFO
2. 审批人可在企业微信收到待办推送，点击直达审批页
3. 审批人操作：同意 / 驳回 / 退回修改；驳回必须填写原因（原因会推送给提交人）
4. 最终审批完成后单据进入"财务审核"队列，财务在承诺时限内完成（报销 1-2 个工作日，差旅 2 个工作日）
5. 财务审核通过 → 出纳排入付款日：每周三、周五（报销类）；紧急付款走特批流程当天处理
6. 付款成功后系统推送到账通知，可在"我发起的"中查看付款回单号

### 6.3 驳回与重提
1. 企业微信收到"您的单据被驳回"推送，点击进入单据详情，顶部红色横幅显示驳回原因
2. 修改：在"我发起的 → 被驳回"中打开单据，点击"修改并重提"
3. 重提后审批流从头开始（已合规的审批节点系统记忆保留，财务审核不重走，但主管节点重新审批）
4. 对驳回有异议：先按意见补充材料重提；仍有异议的联系财务负责人或部门负责人申诉（详见《财务报销常见问题FAQ》）
5. 驳回单据 90 天未重提的自动归档，需重新新建单据（关联的出差申请仍可复用）

## 七、常见错误与处理

| 错误提示 | 原因 | 处理办法 |
|---------|------|---------|
| "预算不足，无法提交" | 部门科目余额不足 | 申请超支特批或更换科目（须财务认可） |
| "发票号码已存在" | 同一发票重复提交 | 删除重复行；确为重复报销的撤回单据 |
| "未找到可用出差申请" | 出差申请未审批通过或已使用 | 先审批出差申请；一张申请对应一张报销单 |
| "超出住宿标准" | 酒店金额超标 | 不用修改金额，系统自动计算自付部分，超标即自付 |
| "附件格式不支持" | 上传了图片版电子发票截图 | 改为 PDF 原件重新上传 |
| "超出市内交通日限额" | 打车费超日上限 | 超限部分系统列自付，或补充特殊事由报部门负责人 |
| "存在未冲销借款" | 借款未清 | 先提交冲账单，或在借款单意见中说明并由部门负责人确认 |
| "单据已超期" | 超过报销时限 | 填写超期说明，需部门负责人在审批意见中确认 |
| "培训额度不足" | 年度 5000 元培训预算用尽 | 超出部分个人承担，或选择免费内部培训 |
| "审批人不存在" | 审批人离职或组织变更 | 联系 HR 确认新审批人后联系财务调整流程配置 |

## 八、统计与查询

- 我发起的：支持按状态（审批中/已通过/已驳回/已付款）、时间范围筛选，导出 Excel
- 部门管理员：可查看本部门全部单据与部门预算执行率（费用管理 → 部门视图）
- 个人年度报销统计：费用管理 → 统计报表 → 个人视图，含差旅、招待、培训分类汇总
- 到账查询：单据详情页"付款信息"区域显示付款日期与回单号；未显示的即未进入付款日
- 发票查验结果：财务审核后在明细行显示"已查验/查验异常"标记

## 九、与财务对接

### 9.1 咨询渠道
- 制度类问题：优先问 SmartFlow 助手（企业微信工作台），7×24 小时，答案附知识库出处
- 单据卡单、审批流问题：财务共享服务台，企业微信"财务服务"或分机 8300，工作日 9:00-18:00
- 专票认证、税务问题：财务部税务岗（企业微信通讯录-财务部-税务专员）
- 系统故障、无法登录：IT 服务台分机 8100

### 9.2 财务审核常见退回原因 Top 5
1. 电子发票上传截图而非 PDF 原件
2. 抬头或税号错误
3. 差旅报销单未关联出差申请
4. 附件金额与明细合计不一致
5. 事由过于简略（如只写"报销"二字）

### 9.3 付款与到账
- 常规付款日：每周三、周五；审批完成时间与最近付款日的间隔即为等待期
- 紧急付款：财务经理 OA 特批后当天处理（适用场景见《资金支付与审批权限办法》）
- 节假日顺延：付款日遇法定假日顺延至节后第一个工作日，以财务部通知为准

## 十、移动端操作要点

- 企业微信端支持全流程：新建、审批、驳回、查询均可完成
- 拍照识别发票：新建单据时点"扫码/拍照识票"，自动识别抬头、税号、金额、发票号码；识别后必须人工复核
- 离线暂存：弱网环境可暂存本地，恢复网络后在"草稿箱"提交
- 指纹/面容审批：企业微信开启后可快速审批，但 5000 元以上单据强制要求再次输入企业微信密码确认

## 十一、快捷键与效率技巧

- Ctrl+N：任意页面快速新建费用报销单
- 批量上传：附件区支持一次拖拽多个 PDF，按文件名排序生成附件清单
- 常用事由库：可维护 10 条常用事由短语（如"XX客户项目驻场差旅"），下拉选择
- 复制历史单据：从"我发起的"中选择已付款单据，点"复制为新单"，适合周期性费用
- 订阅提醒：可订阅"待我审批>10 单"的企业微信周报，避免堆积

## 十二、常见操作问答

**Q：发票原件丢了还能报销吗？**
A：可以走遗失流程：500 元以下支付凭证+情况说明可报；500 元以上还需部门负责人签字。

**Q：一个出差申请可以报几次销？**
A：一张差旅报销单对应一张出差申请；分次报销的（如回程票晚出）需在第一次报销时备注"尚有回程费用待报"，并经财务确认。

**Q：提交后发现自己填错了怎么办？**
A：审批未完成的，可在"我发起的"中点"撤回"，修改后重新提交；已进入财务审核的需联系财务退回。

**Q：审批人休假怎么办？**
A：OA 自动检测审批人休假状态并转交其职务代理人；未设置代理的，提交人可联系其上级在系统中加签。

## 十三、审批人操作指南

### 13.1 进入审批
- 企业微信推送：收到"待我处理"消息卡片，点击直达单据详情页，卡片显示单号、提交人、金额、摘要
- PC 端：OA 首页"待我处理"列表，支持按单据类型、金额、提交人筛选
- 批量审批：列表页勾选多个单据"批量同意"，但单张金额超过 5000 元的单据不参与批量，必须逐张打开确认

### 13.2 审批操作要点
- 同意：点击底部绿色"同意"按钮，流转至下一节点；可在意见框填写备注（非必填，但财务建议大额单据注明业务背景）
- 驳回：点击"驳回"，必须填写驳回原因（必填），原因将推送给提交人并保留在单据历史中
- 退回修改：与驳回类似，但单据回到提交人"草稿修改"状态而非"被驳回"状态，适用于需要私下补充材料的场景
- 加签：审批人可将单据加签给其他人（如需要财务预审意见），加签人处理后单据回到当前审批人
- 转办：审批人长期不在岗时可将待办转办给同事，转办记录留痕，转办人对审批结果负同等责任

### 13.3 审批人责任提示
- 审批人需实质审核：核对费用真实性、票据合规性、金额合理性，不得无脑秒批
- 违规审批连带责任：审批人未尽审核义务导致违规报销的，承担 20% 连带赔偿（见《财务报销制度》违规处理条款）
- 系统对"同一审批人平均审批时长低于 30 秒且月审批量超过 50 单"的行为进行风控标记，财务部定期抽查

## 十五、财务审核视角（提交人须知）

- 财务审核岗使用"审核工作台"，左侧为待审队列，右侧为单据详情与发票查验结果
- 每张单据财务核验：发票真伪（税务查验接口）、金额勾稽（明细合计=票据合计=报销总额）、时限合规、科目正确、审批链完整
- 需要补充材料的，财务选择"退回补充"并写明缺什么材料；补充后单据回到财务队列，审批人节点不重走（财务经理节点例外）
- 审核通过后单据状态变为"待付款"，进入出纳付款池，按付款日规则出款
- 财务每周三、周五上午 10:00 批量处理付款池，10:00 后提交的进入下一批次

## 十六、常见场景速查

**场景 1：出差回来当天就想报销**
A：可以提前整理票据，出差结束日即可提交（系统按行程结束日判断时限起点），但部分票据（如机票）行程结束后才出票，出票后再补提。

**场景 2：一次出差跨两个城市**
A：出差申请添加两个城市；住宿明细按城市分行填写，各城市分别适用当地标准（北京+石家庄行程：北京段按一线标准，石家庄段按省会标准）。

**场景 3：部门负责人就是审批人自己的报销**
A：系统自动将审批人上提至分管高管，避免自审自批。

**场景 4：发票 PDF 太大传不上去**
A：单文件上限 20MB，可压缩 PDF（在线工具即可）或拆分文件；仍超限的联系财务走线下附件通道。

**场景 5：想查一笔报销到了哪一步**
A：SmartFlow 助手问"我的报销单 X 到哪一步了"，或 OA"我发起的"点开单据看流程图，当前节点高亮显示。

## 十七、周期性费用专题操作

### 17.1 通讯费报销
- 经理 200 元/月、总监 500 元/月按月定额报销：每月 1-5 日提交上月通讯费报销单，费用类型选"通讯费"，无需发票（定额）
- 需对外联络岗位凭发票实报的：上传话费发票 PDF，上限 150 元/月，事由注明岗位名称
- 普通员工不报销通讯费，无需提交

### 17.2 培训费报销
- 外部培训需在参训前完成 OA 培训申请审批（部门负责人 + HR）
- 报销时费用类型选"培训费"，系统自动校验本人年度已用额度与 5000 元预算的差额
- 取证类培训（PMP、CPA 等）：上传证书扫描件作为报销附件，考过才可报，未通过的费用自理
- 培训费报销时限：培训结束（或取证日）起 30 天内

### 17.3 业务招待费报销
- 事前必须完成 OA 招待申请（客户名称、人数、事由、预算），报销时关联申请单号
- 明细行填写参与人数，系统自动计算人均金额：人均超 300 元或单次超 3000 元的追加审批节点
- 附件三件套缺一不可：餐饮发票 PDF + 消费明细（水单）+ 参与人员名单（可写在事由或上传名单文件）
- 酒水费用行如出现，财务将核对是否从行政酒库领取；另行购买酒水的招待费行会被驳回

### 17.4 办公用品报销
- 日常办公用品由行政统一采购，员工无需提交报销
- 部门专属特殊用品（部门负责人审批后自行购买，500 元以下）：费用类型选"办公用品"，事由注明"部门专属+物品清单"
- 超过 500 元的特殊用品应走购置申请或由行政代采

### 17.5 报销与工资发放的关系
- 报销款独立于工资：随周三、周五付款日单独打款，不在每月 15 日发薪日合并发放
- 报销款不属于个人所得，免征个人所得税，不并入工资计税，也不作为年终奖计算基数
- 部门费用统计口径：报销款按费用发生部门计入部门预算执行率，与打款渠道无关
- 离职当月未报完的费用：必须在离职交接日前提交，财务在离职工资结算前优先处理已审批完成的报销款
- 工资卡变更的员工：报销单收款账户需同步更新为新卡，否则打款失败退回，需联系出纳更新账户信息

### 17.6 与 SmartFlow 助手的联动
- 查询类：可直接问"差旅报销时限""审批到哪一步""深圳住宿标准多少"，助手从制度知识库检索答案并附出处
- 办理类：助手会引导至 OA 对应入口（企业微信 → 工作台 → OA → 报销中心），不能代为提交单据
- 催办类：助手提供催办链接，点击后向当前审批人发送企业微信提醒
- 帮助类：遇到本手册未覆盖的问题，助手提示转接财务共享服务台人工处理
